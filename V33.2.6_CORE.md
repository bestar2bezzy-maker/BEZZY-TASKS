# Bezzy Tasks V33.2.6 — Core task/reward consolidation

This release advances the V33.2.1 consolidation foundation with the core task lifecycle and financial reward path.

## Implemented core
- User registration/login/me with bcrypt and short-lived JWT access tokens.
- Public task list/detail.
- Authenticated task start and submission.
- Completion states: PENDING -> UNDER_REVIEW -> APPROVED or REJECTED.
- Reviewer authorization for ADMIN/SUPER_ADMIN/MODERATOR.
- Immutable `ledger_entries` as the user financial source of truth.
- Integer minor units and currency on rewards.
- Idempotent task reward credit keyed by completion.
- Wallet balance derived from ledger entries; no direct balance field.
- Request IDs, Helmet, CORS, JSON limit, rate limiting, SQLite WAL/foreign keys inherited from V33.2.1.

## Important production boundary
This is a consolidation core, not a claim that every V33.1/V33.2 module is production-complete. Payment providers, refresh-token rotation, withdrawals, campaigns, surveys, evidence storage, admin finance UI, and other modules remain required before a real-money public launch unless already implemented elsewhere and merged into this codebase.
